# シンプル動画プレイヤー

ブラウザだけで動くローカル動画プレイヤーです。ビルド不要の静的ファイル（HTML / CSS / JS）だけで構成されているので、GitHub Pages にそのまま置けます。

## 機能

- ドラッグ＆ドロップ / ファイル選択で動画を開く
- 再生・一時停止・停止（先頭に戻る）
- 再生速度の変更（プリセット 0.25x〜3x、スライダーで 0.25x〜4x を 0.05 刻み）
- 時間を指定して再生（`90` / `1:30` / `1:02:03` / `1:30.5`、全角数字も OK）
- 「現在位置」ボタンで今の時間を入力欄にコピー
- 10秒スキップ、コマ送り、音量、全画面
- キーボードショートカット（画面下部の一覧を参照）
- 再生速度と音量はブラウザに記憶されます

## セキュリティ

- **動画は一切アップロードされません。** `URL.createObjectURL` でブラウザ内で再生します
- Content Security Policy で外部通信（`connect-src 'none'`）・インラインスクリプト・外部スクリプトを禁止
- 動画ソースは `blob:` URL のみ許可
- ファイル名などは `textContent` で表示し、`innerHTML` は使っていません
- 外部ライブラリ・CDN 依存なし
- 動画を切り替えるときは前の blob URL を解放します

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pages で公開する

1. GitHub に新しいリポジトリを作って、このフォルダの中身を push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
